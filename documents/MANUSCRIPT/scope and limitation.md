## 1\.2 Objectives

### 1\.2\.1 General Objective

The general objective of this study is to design and develop tourvia: a mobile\-based tour management & assistance for tourists & tourist guides in the Philippines\.

### 1\.2\.2 Specific Objectives

__*1\.2\.2\.1 To develop a registration module for tour guides to access the proposed project*__

	This module allows tour guides to register by submitting the required personal and professional information for verification, such as full name, age, email, contact number, and tour guide ID\.

__*1\.2\.2\.2 To develop a login module for tour guides to access the proposed project*__

	This module will enable approved tour guides to log in to the system using their username and password credentials\.

__*1\.2\.2\.3 To develop a functionality that enables tour guides to generate unique access codes for tourists during an active tour*__

	This module allows tour guides to create special access codes that tourists can use to log into the system during ongoing tours\.

__*1\.2\.2\.4 To develop a feature that allows tour guides to create and manage tour itineraries*__

	This module enables tour guides to digitally plan and organize tour itineraries, including destinations, schedules, and time allotments, ensuring tours are well\-structured and easy to follow for both guides and tourists\.

__*1\.2\.2\.5 To develop a mobile application that allows tour guides to monitor tourist attendance*__

	This module provides tour guides with a mobile tool to identify and track tourist attendance throughout the guided tour, ensuring no participant is missed\.

__*1\.2\.2\.6 To develop live location tracking and boundary\-based alert features to improve tourist safety*__

	This module allows tour guides to monitor tourists in real\-time, issue alerts when a tourist moves outside the designated 1 km tour boundary, and guide tourists back to the group\.

__*1\.2\.2\.7 To develop a weather alert module*__

	This module provides real\-time weather information, including conditions such as rain, storms, or extreme heat, to help tourists and tour guides adjust plans and stay safe\.

__*1\.2\.2\.8 To develop an SOS Button feature*__

	This module allows any user \(tourist or tour guide\) to send an immediate alert in case of an emergency, notifying the other party and sharing their current location for rapid assistance\.

__*1\.2\.2\.9 To develop a group chat feature for communication and image sharing between tour guides and tourists*__

	This module provides a centralized chat system for sending messages and images, enabling guides to relay announcements and tourists to remain informed during the tour\.

__*1\.2\.2\.10 To develop and integrate a chatbot\-assisted system for accessing tourist information*__

	This module provides a chatbot that can answer questions and supply information about tourist destinations, including descriptions, location details, and photos, for both tourists and guides\.

### 1\.3\.2 Limitations

#### __1\.3\.2\.1__ The system is designed only for tourist spot in the Philippines\. The users 	cannot use the system outside the country as a location data, Ai chatbot response 	and safety alerts are programmed specifically for Philippines destinations\.  

#### __1\.3\.2\.2__ The reliability of live location and boundary alerts depends on GPS accuracy and network signal\. Poor signal or GPS error may cause delayed or inaccurate tracking for the tours\. 

__1\.3\.2\.3__ The AI chatbot will only respond to questions on locations in the Philippines and can only provide programmed information it cannot answer questions outside of its programmed knowledge\.

#### __1\.3\.2\.4__ The system does not handle online booking, payment, and reservation 	functions\. Implementing capabilities would require additional infrastructure for 	secure financial transactions, compliance with payment regulations, and 	management of third\-party service providers\.

#### __1\.3\.2\.5__ The system features such as live tracking, notifications alert will not function properly if the tourist device is turned off, no internet connection, or GPS is disabled, 

#### __1\.3\.2\.6__ The system required smartphone for users and internet connection to use features such as live location tracking, group chat, AI chatbot, and safety alerts

__1\.3\.2\.7__ The system does not verify the accuracy or authenticity of information provided by the tour guide’s before it is registered in the system\.
